Связать OpsVault

Свяжите текущий аккаунт с вашим аккаунтом OpsVault. Потоки, баннеры и статистика останутся за вами.

Локальный вход сохранится. После подтверждения логин и текущий пароль домонетки будут сохранены в зашифрованном хранилище OpsVault, где их можно посмотреть. Доступ проверяется через OpsVault при обоих способах входа.

Подтвердить связывание

Данные домонетки и локальный пароль сохранятся. Логин и пароль будут отправлены в зашифрованное хранилище OpsVault. Текущие сессии завершатся; далее доступны оба способа входа.

Варианты

Рейтинг учитывает CTR и объём данных: (клики + 1) / (показы + 20). В 20% выборов тестируется вариант с наименьшим числом показов. На странице показывается один вариант каждого оффера.

Конфигурация
1. Трекер

2. Метки
В источнике трафика Binom добавьте свободные токены для dm_source, dm_flow, dm_offer, dm_variant, dm_click. Заполните Parameter и Name по подсказке, Placeholder оставьте пустым. Здесь выберите номера этих токенов.
3. Партнёрки
Добавьте партнёрку и списки статусов: апрув, ожидание, отклон. Выберите её у баннера. Незнакомые статусы останутся неизвестными.
У каждой партнёрки свои списки статусов. Выберите партнёрку у баннера, чтобы применить эти правила к данным Binom.

Партнёрка
Добавьте названия статусов, которые партнёрка передаёт в выбранное поле Binom. Один статус на строку. Названия и регистр должны совпадать. Один статус может быть только в одной категории. Пустые списки оставляют сырые статусы.
Подготовить картинку
Для быстрой витрины: 30–50 КБ на картинку. Рекомендуемая цель — 40 КБ в WebP, максимальная сторона 640 px. Это подходит для компактных баннеров, в том числе по два в ряд на телефоне. Чем больше баннеров, тем важнее небольшой вес каждого. Скорость также зависит от сети посетителя.
Формат WebP. Для достижения веса качество и размеры могут снижаться. Оцените результат в предпросмотре. Время передачи — ориентир, реальная загрузка зависит от сети и сервера.
